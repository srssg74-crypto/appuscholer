# Appuscholar: description for a copyright or licensing discussion

Prepared 7 October 2026 for Dr. Shiv Raj Sharma. This is a factual summary for a lawyer. It is not legal advice.

## What it is

Appuscholar is a research and writing assistant for psychology students, delivered as a single web page that runs in the browser. It has no server of its own. Documents, projects and data stay in the user's browser. Live address: https://srssg74-crypto.github.io/appuscholer/ (repository srssg74-crypto/appuscholer on GitHub).

## Modules (as in the in-app Guide, October 2026)

Writing area with Continue, Improve, Extend, templates, dictation and picture handling. Idea and feasibility check. Research search over OpenAlex, Crossref and PubMed, and a reading shelf for the user's own PDFs. Psychology tools. Design and Ethics: regulatory-pathway wizard, protocol builder, ethics package and approval record, consent form, registration readiness, PI eligibility, budget, AI-use statement. Statistics Lab with APA sentences and a guide to choosing a test. Scale library. A check of numbers in the user's document. Charts and Chart Studio. Qualitative coding. A personal writing-style profile. Citation manager. Presentation maker. Participant-data handling with a personal-data scan. The Cognitive Engagement Layer: "My writing" origin tracker, Draft first mode, devil's advocate, generate-before-reveal practice, viva question, return-after-a-gap recap. Offline mode and install. A guide, a guide helper, a problem report, and first-use terms with an 18+ gate.

## Distinctive design decisions to be described in any filing

An opt-in layer that returns questions instead of text, never grades the student's thinking, and labels each measure for exactly what it measures. A personal-data scan that runs before data enters the Statistics Lab or an AI prompt. An AI-use log and statement generator that never stores the text sent. A rule that every number the app reports is computed in code, not by the AI.
